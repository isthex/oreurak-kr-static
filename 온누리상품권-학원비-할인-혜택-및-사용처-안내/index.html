온누리상품권이란?

온누리상품권은 중소벤처기업부와 소상공인시장진흥공단이 발행하는 유가증권 형태의 상품권으로, 전통시장과 상점가, 일부 가맹 중소상공인 매장에서 사용할 수 있습니다. 지류형, 카드형, 모바일형 세 가지 형태로 운영되며, 정부에서 할인율을 적용해 판매하기 때문에 많은 소비자들이 생활비 절감을 위해 이용하고 있습니다.

온누리상품권 학원비 할인 혜택

할인율 및 구매 한도

  • 개인 구매 시 할인율: 최대 10% 할인
  • 지류형/모바일형: 월 최대 70만 원까지 할인 구매 가능 (카드형은 월 100만 원)
  • 연말 또는 특정 기간엔 구매 한도 및 할인율이 일시적으로 확대되기도 함

적용 가능한 학원 종류

  • 온누리상품권 가맹 등록된 학원에 한해 결제 가능
  • 보습학원, 미술학원, 음악학원, 체육관 등 다양하게 등록되어 있음
  • 단, 학원 자체적으로 가맹 등록을 하지 않은 곳은 사용 불가

온누리상품권 사용처 확대

학원 외 사용 가능한 업종

  • 전통시장 상점, 의류, 식자재, 생필품, 음식점 등
  • 미용실, 안경점, 한의원, 약국 등 생활밀착 업종
  • 지역사랑상품권과 중복 수용하는 가맹점 다수

가맹점 확인 방법

  • 소상공인시장진흥공단 온누리상품권 공식 홈페이지에서 지역별 가맹점 검색 가능
  • 온누리상품권 앱 또는 각 카드사 앱(카드형의 경우)에서도 확인 가능

온누리상품권 구매 및 사용 방법

지류, 카드형, 모바일 상품권 구입 방법

  • 지류형: 농협, 신한은행, 우리은행 등에서 신분증 지참 후 구매
  • 모바일형: 농협올원뱅크, 비플제로페이 앱 등에서 간편 구매
  • 카드형: 하나카드, 비씨카드 등을 통해 충전형 선불카드 방식 사용

결제 시 유의사항

  • 잔액은 현금으로 거슬러주지 않음 (부분 사용 불가)
  • 유효기간은 발급일로부터 5년 (모바일/카드형은 확인 필요)
  • 지류형은 오프라인 매장만 사용 가능, 모바일/카드형은 온라인 일부 가맹점도 사용 가능

자주 묻는 질문(FAQ)

Q1. 모든 학원에서 온누리상품권을 사용할 수 있나요?

아닙니다. 온누리상품권 가맹점으로 등록된 학원에서만 사용이 가능합니다. 결제 전 해당 학원이 가맹점인지 반드시 확인하세요.

Q2. 온누리상품권으로 학원비 결제 시 현금영수증 발급이 가능한가요?

지류형 상품권은 현금영수증 발급이 되지 않지만, 카드형과 모바일형은 결제 시 자동으로 국세청에 등록되어 현금영수증 처리가 가능합니다.
