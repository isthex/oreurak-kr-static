삼성 핸드폰 초기화 전 반드시 확인할 것

초기화는 기기의 모든 데이터를 삭제하는 작업이기 때문에 아래 항목을 사전에 확인하고 진행하는 것이 중요합니다.

  • 중요 데이터 백업: 갤럭시 클라우드, 구글 드라이브, 외장 메모리 등에 백업 필수
  • 삼성 계정 및 구글 계정 로그인 상태 확인: 초기화 후 재로그인 필요 (FRP 보안 기능)
  • 배터리 50% 이상 권장: 초기화 중 전원 꺼지면 오류 발생 가능

방법 1. 설정 메뉴에서 초기화하기 (정상 작동 시)

기기가 정상 작동하고 있다면, 설정 메뉴에서 간단히 공장 초기화를 진행할 수 있습니다.

STEP 1. 설정 → 일반 → 초기화 진입

  • [설정] 앱 실행
  • [일반] 항목 탭
  • [초기화] 메뉴 클릭

STEP 2. 기기 전체 초기화 진행

  • [기기 전체 초기화] 선택
  • 화면의 안내에 따라 ‘초기화’ 버튼 클릭
  • 삼성 계정이 등록된 경우, 계정 비밀번호 입력 필요

STEP 3. 자동 재부팅 및 초기화 완료

  • 초기화 후 스마트폰이 자동 재부팅되며, 공장 상태로 복원
  • 재설정 화면에서 계정 재로그인 후 사용 가능

방법 2. 복구모드(Recovery Mode)에서 초기화하기

기기가 먹통이거나 비밀번호를 잊어버렸을 때는 하드웨어 버튼을 활용한 복구모드 초기화가 유용합니다.

STEP 1. 전원 완전 종료

  • 전원 버튼 길게 누른 후 ‘전원 끄기’
  • 배터리 일체형은 강제 종료로도 가능

STEP 2. 버튼 조합으로 복구모드 진입

  • [전원 버튼] + [볼륨 업] 버튼 (일부 모델은 [빅스비 버튼] 포함)
  • 삼성 로고가 뜨면 버튼에서 손을 뗌

STEP 3. Wipe data/factory reset 선택

  • 볼륨 버튼으로 이동, 전원 버튼으로 선택
  • [Yes] 선택 후 초기화 진행

STEP 4. 초기화 완료 후 재부팅

  • [Reboot system now] 선택 → 기기 재시작
  • 공장 초기 상태로 복원 완료

초기화 후 꼭 해야 할 작업

  • 구글 계정, 삼성 계정 재로그인
  • 백업한 데이터 복원
  • 와이파이, 블루투스 등 설정 재구성

자주 묻는 질문(FAQ)

Q1. 초기화하면 연락처와 사진도 다 사라지나요?

네. 초기화 시 저장된 모든 데이터가 삭제되므로 반드시 백업 후 진행해야 합니다.

Q2. 계정 비밀번호를 몰라도 초기화 가능한가요?

초기화는 가능하나, 이후 계정 인증(FRP) 절차에서 기존 구글 또는 삼성 계정 비밀번호를 입력해야 기기 사용이 가능합니다.

Q3. 초기화 후에도 앱이 남아있는 경우가 있나요?

공장 기본 탑재 앱 외에는 모두 삭제되며, 초기화 후 앱스토어에서 새로 설치해야 합니다.
