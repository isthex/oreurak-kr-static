연금복권이란 무엇인가요?

연금복권은 2011년 처음 출시되었으며, 당첨 시 매월 일정 금액을 20년간 지급받을 수 있는 복권입니다. 현재는 연금복권720+이라는 이름으로 운영되고 있으며, 매주 1등 1명에게 20년간 월 700만원(세전)의 당첨금을 지급합니다.

연금복권의 특징

1. 매주 수요일 추첨 2. 고정 금액으로 장기 수령 가능 3. 실수령액은 세금 공제 후 지급 4. 일시불이 아닌 ‘연금형’ 수령 방식

연금복권 구매 가능한 곳과 방법

연금복권은 온라인과 오프라인 모두에서 구매할 수 있습니다. 특히 온라인 구매는 간편성과 접근성 면에서 많은 사람들이 선호하고 있습니다.

오프라인 구매 방법

1. 복권판매점(편의점, 가판대 등) 방문 2. 연금복권 요청 후 금액 지불(1매 1,000원) 3. 종이 복권 수령 후 보관

온라인 구매 방법

1. 동행복권(www.dhlottery.co.kr) 회원가입 2. 로그인 후 ‘연금복권720+’ 메뉴 선택 3. 번호 직접 선택 또는 자동 선택 후 결제 4. 구매내역에서 확인 가능

연금복권 당첨 구조 및 당첨금 안내

연금복권은 추첨 방식과 당첨 기준이 다소 독특합니다. 총 7자리 숫자 중 앞 2자리는 조, 뒤 5자리는 번호로 구성됩니다.

1등부터 7등까지 당첨금 차이

1등: 매월 700만원씩 20년간 지급 2등: 매월 100만원씩 10년간 지급 3~7등: 고정금액 일시불 지급(각 100만원 이하)

보너스 번호와 당첨 조건

보너스 번호는 조와 상관없이 번호만 일치할 경우 적용됩니다. 예를 들어, 2등의 경우 조는 달라도 보너스 번호와 일치하면 당첨됩니다.

연금복권 당첨 확인과 수령 절차

당첨 여부는 오프라인 구매자의 경우 복권을 직접 확인해야 하며, 온라인 구매자는 시스템에서 자동으로 확인 가능합니다.

인터넷 당첨 확인 방법

1. 동행복권 홈페이지 접속 2. ‘당첨결과’ 메뉴 → 연금복권720+ 선택 3. 회차 선택 후 당첨번호 확인 4. 구매 복권과 번호 대조

당첨금 수령 시 유의사항

1. 1등~2등은 신분증 지참 후 농협 본점 직접 방문 2. 3등 이하는 가까운 농협 지점에서 수령 가능 3. 1년 이내에 수령하지 않으면 당첨금 소멸 4. 세금은 3억원 초과분 33%, 이하 22% 차등 부과

연금복권과 로또 차이점 비교

많은 사람들이 연금복권과 로또를 혼동하지만, 둘은 매우 다른 특성을 가집니다. 주요 차이점은 다음과 같습니다.

당첨금 지급 방식 차이

로또: 1등 당첨 시 세후 약 15~17억원 일시불 지급 연금복권: 1등 당첨 시 세전 월 700만원씩 20년간 지급 → 목돈이 필요한 경우엔 로또, 안정적인 수익을 원한다면 연금복권

투자 성격 및 추천 유형

로또: 고위험·고수익형 → 일확천금 지향 연금복권: 저위험·안정 수익형 → 꾸준한 수입 지향 → 자금 관리 스타일에 따라 선택 필요

자주 묻는 질문(FAQ)

Q1. 연금복권은 매주 언제 추첨하나요?

매주 수요일 오후 7시 5분에 MBC에서 생방송으로 추첨됩니다. 결과는 당일 오후 8시 이후 동행복권 홈페이지에서 확인 가능합니다.

Q2. 당첨 후 세금은 얼마나 내야 하나요?

1등 연금 당첨금의 경우, 월 700만원 중 약 22%의 세금이 공제되어 약 546만원 정도가 매월 실수령됩니다. 일시불 당첨금은 3억원 초과분에 대해 33% 세율이 적용됩니다.
