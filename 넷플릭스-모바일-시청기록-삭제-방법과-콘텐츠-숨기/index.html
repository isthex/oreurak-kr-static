넷플릭스에서 시청한 콘텐츠는 자동으로 기록되어 향후 추천 콘텐츠에 영향을 주거나, 가족과 함께 사용하는 계정이라면 시청 이력을 숨기고 싶은 경우도 있습니다. 하지만 넷플릭스 모바일 앱에서는 시청기록 삭제가 직접적으로 불가능브라우저를 통해 삭제하는 방법과 ‘시청 중인 콘텐츠’ 줄에서 항목을 지우는 팁까지 모두 소개합니다.

👉넷플릭스 바로가기

넷플릭스 시청기록은 왜 삭제해야 할까?

넷플릭스는 시청한 콘텐츠를 기반으로 유사한 콘텐츠를 추천합니다. 그러나 타인과 계정을 공유하거나, 잠깐 시청한 콘텐츠 때문에 추천 목록이 어지러워졌다면 시청 기록 삭제가 필요합니다. 또한 자녀가 잘못된 콘텐츠를 본 경우에도 기록 정리는 필수입니다.

모바일 앱에서 시청기록 삭제가 불가능한 이유

2025년 현재 기준으로 넷플릭스 앱 자체에서는 시청기록 삭제 기능이 제공되지 않습니다. 이는 사용자 보안과 기능 제한을 위한 정책 때문입니다. 대신, 모바일 웹 브라우저(크롬, 사파리 등)를 통해 넷플릭스 웹사이트에 접속하여 기록을 삭제할 수 있습니다.

모바일 브라우저로 시청기록 삭제하는 방법

넷플릭스 계정 로그인 후 메뉴 이동

  1. 모바일 웹 브라우저에서 넷플릭스 공식 웹사이트 접속
  2. 로그인 후 우측 상단 메뉴에서 ‘계정’ 선택
  3. ‘프로필 & 자녀 보호 설정’에서 해당 프로필 클릭
  4. ‘시청 기록’ 항목 → ‘보기’ 클릭

프로필별 시청 기록 숨기기 방법

  • 삭제하고 싶은 콘텐츠 옆의 ⊘ 아이콘(숨기기)을 클릭
  • 시리즈 콘텐츠의 경우 ‘시리즈 전체 숨기기’도 가능
  • 하단의 ‘모두 숨기기’를 클릭하면 전체 시청 기록 삭제 가능

삭제 후 약 24시간 이내에 전체 디바이스에서 기록이 사라지며 추천에도 반영되지 않습니다.

‘시청 중인 콘텐츠’ 줄에서 콘텐츠 삭제하는 방법

앱 내 삭제 가능한 항목

넷플릭스 앱에서는 ‘시청 중인 콘텐츠’ 섹션에서 개별 콘텐츠 삭제는 가능합니다. 삭제 방법은 다음과 같습니다.

  1. 넷플릭스 앱 실행 → 시청 중인 콘텐츠 목록으로 이동
  2. 삭제하려는 콘텐츠 썸네일 길게 누르기 or 상세 보기 탭
  3. ‘시청 중인 콘텐츠에서 제거’ 선택

삭제가 안 되는 경우 대처법

일부 콘텐츠는 앱이 최신 버전이 아니거나 일시적인 오류로 인해 삭제 옵션이 나타나지 않을 수 있습니다. 이 경우 앱을 업데이트하거나, 다시 로그인한 후 시도해 보세요.

키즈 프로필 시청기록 관련 주의사항

삭제 불가능한 프로필 정보

키즈 프로필은 시청기록 숨기기가 불가능합니다. 넷플릭스 정책상, 자녀 보호 기능을 위해 기록 삭제가 제한되어 있습니다. 자녀의 시청 기록을 관리하려면 일반 프로필을 만들어주고 시청 제한 설정을 걸어 사용하는 것이 안전합니다.

부모 통제 기능 활용법

‘계정 → 자녀 보호 설정’에서 다음 기능을 사용할 수 있습니다.

  • 시청 가능 등급 제한
  • PIN 설정으로 접근 제한
  • 특정 콘텐츠 블록 기능

자주 묻는 질문(FAQ)

Q1. 모든 시청기록을 한 번에 삭제할 수 있나요?
네. ‘시청 기록’ 페이지 하단에서 ‘모두 숨기기’ 옵션을 선택하면 해당 프로필의 전체 시청 기록이 삭제됩니다.

Q2. 시청기록을 삭제하면 추천 콘텐츠도 초기화되나요?
부분적으로 초기화됩니다. 삭제된 콘텐츠는 추천 알고리즘에 더 이상 반영되지 않지만, 전체 추천 시스템은 시청 내역 전반에 따라 유지됩니다.
