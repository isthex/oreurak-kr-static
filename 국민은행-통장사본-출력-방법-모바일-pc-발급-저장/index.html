국민은행 통장사본이란

국민은행 통장사본은 계좌 정보가 포함된 공식 문서로, 계좌번호, 예금주명, 은행명, 개설일 등의 기본 정보가 기재되어 있습니다. 과거에는 실물 통장의 첫 페이지를 복사하여 제출했지만, 현재는 전자 통장사본을 발급받아 제출하는 것이 일반적입니다. 국민은행에서는 통장사본과 계좌개설확인서를 동일하게 취급하므로 어떤 방식으로 발급받든 공식 증명서로 활용할 수 있습니다.

모바일 KB스타뱅킹 앱으로 통장사본 발급

국민은행 통장사본 출력을 위해 가장 간편한 방법은 KB스타뱅킹 모바일 앱을 이용하는 것입니다. 스마트폰에 앱을 설치하고 로그인한 후 전체계좌조회에서 원하는 계좌를 선택합니다. 거래내역조회 화면에서 우측 상단의 톱니바퀴 아이콘을 누르면 계좌 관리 메뉴가 나타납니다.

  • KB스타뱅킹 앱 실행 후 로그인
  • 전체계좌조회 메뉴 선택
  • 통장사본이 필요한 계좌의 점 3개 버튼 클릭
  • 통장사본보기 메뉴 선택
  • 통장사본 저장 또는 공유하기 버튼 클릭

모바일 앱 통장사본 저장 방법

KB스타뱅킹 앱에서 통장사본보기를 선택하면 계좌 정보가 포함된 통장사본이 화면에 표시됩니다. 하단의 통장사본 저장 버튼을 누르면 이미지 파일로 핸드폰 갤러리에 자동 저장됩니다. 저장된 이미지는 카카오톡이나 이메일로 즉시 전송할 수 있으며, 모바일 프린터를 이용해 바로 출력도 가능합니다.

PC 인터넷뱅킹으로 통장사본 출력

PC에서 국민은행 통장사본 출력이 필요한 경우 인터넷뱅킹을 이용합니다. 국민은행 홈페이지에 접속하여 로그인한 후 개인 메뉴에서 뱅킹관리를 선택합니다. 제증명발급 항목 하위에 있는 통장사본 메뉴를 클릭하면 보유 계좌 목록이 표시됩니다.

PC 통장사본 출력 절차

계좌 목록에서 통장사본이 필요한 계좌를 확인한 후 우측의 한글 또는 영문 버튼을 클릭합니다. 한글 버튼을 선택하면 국문 통장사본이, 영문 버튼을 선택하면 영문 통장사본이 새 창으로 열립니다. 인쇄 버튼을 클릭하여 프린터로 직접 출력하거나 PDF 파일로 저장할 수 있습니다.
